# SinoPOP · 音乐实物

本包为视觉提案与打样文件，包含 6 套名片、5 张现场物料概念效果图、6 张主办方介绍氛围图。所有效果图和氛围图均为 AI 生成摄影底图；它们不证明 SinoPOP 曾举办相应演出，也不代表实际场地、艺人、观众人数或已实现的印刷工艺。

请先打开 `preview.png` 浏览 6 个名片方向。`review.html` 另外汇集全部文件链接；其资源链接已检查，但当前浏览器安全策略禁止打开本地 file 协议，因此网页实际渲染未验收，未绕过该限制。`task-01-cards`、`task-02-onsite`、`task-03-profile` 是三个交付文件夹；`assets` 保存原始标志、真实字体和字体许可证。文件名均为 ASCII。

## 01 / 名片

通用成品为美国标准 **3.5 × 2 in = 88.9 × 50.8 mm**，竖版相应旋转尺寸。每边出血 **0.125 in = 3.175 mm = 9 pt**，裁切线在出血外侧。所有印刷稿有 MediaBox、TrimBox、BleedBox。设计文字最小 **7 pt**；大号中文姓名和标题用 Noto Sans SC Heavy 900，小号中文按同行英文匹配 Regular 400 或 Bold 700（另附 Medium 500 静态实例）。英文及数字用 Archivo，大编号用 Archivo ExtraBold 800。PDF 内嵌实际字体子集；SVG 内嵌 WOFF2 字体子集，文字保持可编辑，完整 TTF 随包附上。

每个方向的共有文件：

| 文件 | 内容与用途 |
|---|---|
| `front.svg` / `back.svg` | 正反面可编辑平面稿，成品尺寸，不含出血；内嵌原始 SVG 标志及字体 |
| `print.pdf` | 两页正反面视觉印刷母稿，9 pt 出血、裁切线；特殊结构需配合下面的独立工艺文件 |
| `size-90x54-check.pdf` | 90 × 54 mm（竖版 54 × 90 mm）适配校验，内容等比居中、背景补足，标志不作非等比拉伸 |
| `front-preview.png` / `back-preview.png` | 从实际 PDF 裁切框渲染的平面预览 |
| `mockup.png` | AI 产品摄影底图与真实排版/标志的后期合成效果，2400 px 长边或以上 |
| `construction-guide.svg` | 该方向的结构说明图；工艺线不作为彩色印刷图层 |

### 01-ticket / 票根

横版右侧三分之一为亮绿票根，撕线位于距左边 59.27 mm；两端半圆缺口半径 2.12 mm。主体墨黑、白字姓名、大绿编号，票根中文“入场”在英文 ADMIT ONE 前。`No. 0001` 是用户指定的示例流水号；条形纹理只是装饰，不可扫码。

**工艺：** 双面印刷后打虚线撕孔并模切两个半圆缺口，先打样确认双面对位和撕开手感。

**适合 SinoPOP：** 交换名片像递出一张入场票，音乐 promoter 的身份在触摸和动作中就能被理解。

### 02-setlist / 歌单

正面纸白、撕边绿胶带、黑色粗横线，联系方式排成四首曲目；背面墨黑原始白标与 TONIGHT'S SETLIST。胶带是印刷图形，不需要真实胶带覆盖姓名。

**工艺：** 采用非涂布纸双面印刷即可；撕边只印在画面内，无须额外模切。

**适合 SinoPOP：** 与入口歌单、现场编号及主办方曲目目录共用同一套语言，信息清晰，适合持续补印。

### 03-vinyl / 黑胶封套

`front.svg` 和 `print.pdf` 第一页表示组装后能从圆窗看到内卡唱片的视觉状态，不能把该绿色圆形误当封套上的印色。

附加文件：`sleeve-front-ink.svg`、`sleeve-ink-print.pdf` 为封套墨面；`insert-front.svg`、`insert-back.svg`、`insert-print.pdf` 为独立内卡。内卡建议裁切 **86.9 × 48.8 mm**，小于外套；需根据实际纸厚确认松紧。圆窗直径 41.63 mm，圆心在外套正面 (61.74, 25.40) mm。内卡唱片图案与窗口对齐。结构见总工艺 PDF。

**工艺：** 黑色折片加上下两条 6 mm 胶翼，圆形模切窗露出抽卡上的绿色唱片；右侧开口抽出联系方式。

**适合 SinoPOP：** 将业务关系变成可以收藏的“唱片”，适合重点艺人、场地与合作伙伴交流。

### 04-backstage / 后台证

竖版，成品 50.8 × 88.9 mm，圆角半径 2.12 mm（约 8 px），顶部 12.0 × 1.76 mm 圆头挂绳孔。白色孔洞是结构位置示意，实际需冲孔。联系方式与姓名同在正面，背面保留品牌识别。

本轮正面绿色带改为 **主办方 PROMOTER**；背面仅保留白标和 `sinopop.us`，移除“后台通行证 / ALL ACCESS”。名片只表达主办方身份，避免与真实现场的全区通行证件混淆。任务二真实工作物料上的 ALL ACCESS 保持不变。

**工艺：** 双面印刷、圆角模切、顶部冲挂绳孔，挂绳作为独立物料选配。

**适合 SinoPOP：** 借用后台证件的结构呈现主办方身份，用于现场交流，但不传达实际场馆通行权限。

### 05-jcard / 磁带内页

平面 `front.svg` / `back.svg` 是折后的封面与主内页。真正的展开文件是 `spread-outside.svg`、`spread-inside.svg` 和 `construction.pdf`。展开尺寸 **139.7 × 50.8 mm**，外侧从左至右为 38.1 mm 背折翼、12.7 mm 窄脊、88.9 mm 封面，窄脊竖排 [姓名]；内面已按双面对应关系镜像安排。

**工艺：** 两道压痕、三面折页。此为保留标准名片封面尺寸的迷你 J-card，可展示于透明磁带盒内；并非标准磁带盒满尺寸内衬，须按实际盒型打样，不能直接声称严丝合缝。

**适合 SinoPOP：** 打开时逐步出现联系方式，有实体音乐出版物的翻阅感与收藏感。

### 06-material / 材质冲击

600 gsm 黑色棉纸、亮绿刷边，正面姓名盲压凹，背面原始白标及白色文字。`front.svg` / `print.pdf` 的炭灰姓名只用于在平面上标出压凹位置，并不是灰墨印刷指示。

附加文件：`deboss-mask.svg` / `deboss-mask.pdf` 是单独压凹版；`front-ink.svg` / `ink-print.pdf` 是独立印色版。印厂应将压凹版和白墨版分别处理，不把灰字直接印在纸上。

**工艺：** 600 gsm 黑棉纸、盲压凹、背面不透明白墨、亮绿刷边；纸厚、压痕深度和边漆覆盖以实体打样确认。

**适合 SinoPOP：** 将舞台的黑暗和绿色识别压缩进触感与卡片边缘，适合少量重要商务交换。

### 推荐落地的两款

1. **01 票根：主力品牌名片。** 品牌辨识、音乐关联与互动动作最集中；即使只看轮廓、撕线和绿票根，也能记住 SinoPOP。先做小批工艺样，验证耐用性和撕孔强度。
2. **02 歌单：日常交换与团队通用。** 四行联系信息容易扫读，制作结构简单，与已确定的现场导视完整衔接，适合多人、多次更新。

## 字体、色彩与标志

- 字体：Archivo Regular 400、Bold 700、ExtraBold 800；Noto Sans SC Regular 400、Medium 500、Bold 700、Heavy 900，均由真实可变字体生成静态实例，随附 SIL Open Font License。小号 `[微信号]` 等中文与 Archivo Regular 同行时采用 Regular；和 Archivo Bold 同行的小字采用 Bold；大号姓名、标题保留 Heavy。SVG 为重新嵌入的字体子集；完整字体便于后续替换占位。部分矢量软件可能忽略 SVG 内的网页字体，遇到此情况安装随包 TTF，并检查文字重排。
- 平面设计只用：墨黑 `#111318`、炭灰 `#1B1E24`、纸白 `#F7F8F4`、亮绿 `#73F64B`；辅助灰 `#B7BDC5`、`#5A616C`、`#3A3F48`、`#D8DBD3`。没有粉色、琥珀色、红色、发光、金属标志或假 3D 图形。亮绿文字只出现在深色底上。
- 标志：只用所供 `sinopop-logo-white.svg` / `sinopop-logo-black.svg`；原始 SVG 字节原样复制并嵌入，白标用于深底，黑标用于浅底。原文件内部的 `#FFFFFF` / `#000000` 为不可改色的原始标志例外。没有描边、重绘或单独拉伸。摄影中的贴合仅将整个印刷平面映射到实体表面。
- 摄影像素包含物理光照、自然肤色、材质、颗粒和抗锯齿形成的连续色值，不可能逐像素只剩 8 个十六进制颜色；8 色限制在平面设计及后期叠加层执行。AI 底图保持黑白绿主色，没有使用真实红色现场照片作为新活动证明。

## 占位与输出边界

`[姓名]`、First Last、Title · Team、`+1 [000 000 0000]`、`[微信号]`、`name@sinopop.us` 均为示例联系信息；姓名、电话和艺人资料未编造。`sinopop.us` 使用用户给定域名。`No. 0001`、01–06 为用户要求的示例编号。二维码、合作伙伴、专辑画面与活动安排保持占位。未加入实际场地名、日期、票价或艺人姓名。

AI 原图的原生长边低于 2400 px；最终 PNG 用保留构图的裁切与高质量重采样达到指定交付尺寸，**不声称为原生 2400 px 摄影细节**。原始输出路径和尺寸在各 receipt 中记录。

原有 `print.pdf` 等仍为带出血、裁切线和内嵌字体的 **RGB 打样母稿**，本轮更新文字后继续保留 RGB 色彩模式。01 票根、02 歌单、06 材质另增 `print-cmyk-spot.pdf`：亮绿使用真正的 PDF `/Separation /SP-GREEN` 专色通道，其余绘色转换为 DeviceCMYK，页面框、矢量路径和字体子集保持不变。专色命名仅为 **SP-GREEN**，不指定具体色号，由印厂对应油墨。

**亮绿建议用荧光专色，需实物打样比对。** PDF 中的 CMYK 替代色仅用于屏幕预览，不是荧光油墨配方或实际颜色承诺。四色转换为未采用印厂 ICC 的通用数学转换，并非印厂特性化颜色匹配或 PDF/X 认证；交印时仍应由印厂按纸张与设备核定。06 专色版以 `ink-print.pdf` 为基础，不包含压凹姓名灰字，压凹仍使用独立 `deboss-mask.pdf`；黑棉纸的白色图文需要不透明白墨工艺，不能用零墨量的 CMYK 白色替代，印厂应依据原白色对象另行制白墨版。绿色刷边亦需单独安排工艺。

所有刀模、孔位、折页、胶翼和压凹深度均应做实体打样验证。技术结构稿线条不应直接混入印刷面。
