# Profile atmosphere image prompts

All six images were generated with the built-in image_gen tool. These are AI-created concept photographs and must not be represented as documentation of SinoPOP events. No readable type or logo has been composited into these images. The supplied real event photograph was not reused.

The image generator returned lower-resolution rasters despite the requested sizes. Final PNGs use a composition-preserving crop and high-quality bicubic resampling to a 2400 px long edge. Upscaling does not add true native detail; original files and exact crop rectangles are recorded in receipt-profile.json. Photographic lighting, skin and antialiasing naturally contain continuous tonal values; this is not a claim that every photo pixel equals one of the eight flat brand swatches.
