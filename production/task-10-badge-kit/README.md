## 比 task-06 多了什么
- **整张卡按「哪一方」上色，和挂绳同色**：主办团队荧光绿 · 艺人方黑（艺人粗绿框、艺人团队细绿框）· 嘉宾白 · 媒体灰 / 制作灰加细黑框。远处一眼分得出我方和艺人方。
- **工牌正面像一张票**：标志 + 「通行证 PASS」→ 身份（中文最大、英文次之）→ 姓名或职位 + 编号 → 撕票线 → 通行格 1–4，格下写区域名。撕票线只是印刷图案，不模切。
- **反面**：同色 + 身份字（翻面也能认出身份），下面歌单式 01 场内 … 04 休息室、图例、佩戴须知、编号。
- **职位与编号**：CSV 可选列 `no`（工号/编号）和 `title`（职位，印在姓名下）。通用证号段：检票员 1001 起、工作人员 2001 起、艺人 3001 起、经纪人 4001 起、艺人团队 4501 起。
- **完全通用**：不印日期、场次、场地，任何一场都能直接用；通用证靠编号登记发放、散场收回。
- **挂绳**：单元 = 标志 · 英文身份 · 中文身份 · 刻度条；左右两半互为 180°，戴上后两侧都从工牌往上读；两端 15 mm 夹片位、正中 50 mm 颈后安全扣位不印字。黑绳为双色（白标 + 荧光绿字），其余单色黑。
- **五金统一哑黑**：夹片、圆环、龙虾扣、安全扣。
- **工艺**：PVC 0.76 mm 白芯 + 双面哑膜（舞台灯下不反光）；深色是印出来的，白字白标露白芯，不需要白墨；姓名编号走可变数据。
- **通用证（重复使用）**：name 写 `BLANK` 时不印姓名，职位（title）放大，下面印「通用证 · 散场交回」，反面第一条须知改为「本证当场有效，散场交回」。每场发放、按编号登记、散场收回。

## 重新生成
```bash
pip install -r requirements.txt
python build_badges.py                                        # 全部样稿
python build_badges.py --batch 名单.csv --output 输出文件夹     # 真实名单，列 name,role,zones，可选 no,title
python compose_badge_mockup.py                                # 装配示意
```
编号按 CSV 行号从 0001 起。生产说明改完后用浏览器打印 `brief/merchant-brief.html` 为 A4 PDF（打开背景图形），版本号加一。

所有姓名、日期、数量、地址都是占位；荧光绿必须实物打样。
