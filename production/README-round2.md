## 文件后缀

- `*-rgb.pdf`：RGB 屏幕／内容打样。保留出血、裁切线、TrimBox、BleedBox。
- `*-print.pdf`：其余色转 CMYK，平面亮绿为独立 `/Separation /SP-GREEN` 专色版。无绿色内容的页面不建立无效绿版。相同页面框和字体嵌入。
- `*-technical.pdf` / `*-technical.svg`：仅含切线、打孔、折线或装配边界；有相应工艺的物料才附。实线切、虚线折或工艺边界，详见该目录说明；不得印在成品正背面。
- `*.svg`：文字保持可编辑，嵌入实际字体子集；并非把文本转为图片。修改或添加新字后应通过脚本重新生成子集。
- `*-preview.png`：成品裁切范围的 RGB 预览，长边至少 2400 px；手机按指定 1080 × 1920 px。细长手环／挂绳按实际比例显示。
- `*-layout.json`：尺寸、字号与文字基线记录。`batch-example/` 是真实执行的占位批量样张，不是采购数量或真实人员名单。
- `qa-summary.json` / `qa-summary.md`：本轮汇总 QA；`qa-evidence/` 是独立内容检查和 100% 像素基线检查证据。`MANIFEST.json` 列出增量包全部文件及 SHA-256。

## 字体、色彩、标志

英文与数字：Archivo Regular 400、Bold 700、ExtraBold 800。中文：Noto Sans SC Regular 400、Medium 500、Bold 700、Heavy 900。大号姓名和标题用 Heavy；小字按同行英文匹配 Regular／Medium／Bold。所有印刷实际文字不小于 7 pt。远读功能词按附件字高表核查字形墨迹高度，详细数值见 `task-07-signage/signage-height-qa.json`。

平面色仅使用墨黑 `#111318`、层级面 `#181A1F`、纸白 `#F7F8F4`、亮绿 `#73F64B`，以及 `#B7BDC5`、`#5A616C`、`#3A3F48`、`#D8DBD3`。大面积深面板统一层级面；手环 SVIP、ARTIST / ARTIST TEAM / PRODUCTION 的墨黑身份色带、黑挂绳均保持墨黑。标识只有箭头使用绿，英文功能词使用浅灰全大写。浅色底没有亮绿色文字。生产色表将原键名调整为 `surface`；代码保留 `NAVY = SURFACE` 兼容别名，其值仍为新层级面。

两份原始 SVG 标志的字节与第二轮附件相同。白标用于深底、黑标用于浅底，不描摹、不改色、不加效果。原标志内部自带的纯黑／纯白予以保留；照片自然像素和抗锯齿边缘不作为八色平面色板违例。

## 印厂交接

**亮绿建议用荧光专色，需实物打样比对。** `SP-GREEN` 只是专色通道名称，不指定任何油墨商品色号。PDF 内替代 CMYK 数值仅供屏幕显示，不是荧光实物配方。其他平面色与照片已转换到 CMYK；照片里的自然绿属于照片 CMYK，不强制拆成专色。尚未依据特定印厂 ICC 做纸张色彩认证，不标称 PDF/X。

新层级面 `#181A1F` 使用现有引擎的同一换算方式，在印刷 PDF 中为 **C 22.580645%、M 16.129032%、Y 0%、K 87.843137%**；PDF 归一化绘色数值约为 `0.225806 0.161290 0 0.878431`。这是本次实际写入的过程四色数值，不是专色色号，也没有改变原转换流程。

**黑卡或深色底材上的白字、白标需要白墨版。** 当前印刷文件保留 CMYK + SP-GREEN；电子白色／零 CMYK 不等于白墨通道。若采用白纸印深底，可反白；若采用黑色棉纸、深色 Tyvek 或其他深色原材，请印厂据原矢量建立不透明白墨／必要白墨底版，并实样确认遮盖力与套印。

按 100% 实际尺寸输出，不使用“适合页面”。先核对 TrimBox 成品尺寸与 BleedBox，再按技术 PDF 模切、打孔、压痕。封套胶翼、内卡滑动间隙、挂孔扣件、手环粘扣方向及桌卡折返须做白样。易拉宝底部 150 mm 收卷区保持空白。二维码方框没有编码，替换真实二维码并完成扫码测试后才可生产。
