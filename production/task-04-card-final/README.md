# 黑胶封套名片 · V24 定稿

大号编号由方案编号改为曲目编号 A1。原来的版式、圆窗和缩进内卡尺寸保留；大面积深底更新为层级面。人员信息均为方括号占位。

- `sleeve-rgb.pdf` / `sleeve-print.pdf`：封套外侧展开印刷面，177.8 × 62.8 mm；折后 88.9 × 50.8 mm。左侧为背面、右侧为正面；右侧开口。
- `insert-rgb.pdf` / `insert-print.pdf`：86.9 × 48.8 mm 内卡，第一页唱片面、第二页联系方式。
- `*-technical.pdf` / `*-technical.svg`：单独的 1:1 刀模；实线为切线、虚线为压痕折线。刀模绝不可叠入油墨版。
- `*.svg`：文字可编辑、字体子集和原标志内嵌的印刷母版。`*-preview.png` 为 RGB 裁切范围预览；`assembly-preview.png` 为圆窗与内卡组合示意，不作为印刷分色。
- `staff.csv`：仅含占位内容的输入示例。`batch_staff.py` 输出每人的内卡 RGB 打样、CMYK + SP-GREEN 印刷、SVG 和预览，不改封套。

运行示例：`python task-04-card-final/batch_staff.py --csv task-04-card-final/staff.csv --out task-04-card-final/batch-output`。脚本先验证整份非空 CSV，再输出；过长姓名或联系方式会明确报错，不会自动压缩至小于 7 pt，后续坏行不会留下前几人的半套文件。

封套与内卡出血均为 3.175 mm（0.125 in）。圆窗直径 41.63 mm，正面局部中心 (61.74, 25.4) mm；展开图中心 (150.64, 31.4) mm。上、下各 6 mm 胶翼，先模切再压痕、粘合。胶位内侧不印刷或上光，按纸厚试装，防止胶侵入插卡通道；裁切孔位与组装前须做白样。

亮绿建议用荧光专色，需实物打样比对。SP-GREEN 是分色名称，印厂对应实际油墨，不指定商品色号。若使用黑色或深色原纸，白字和白标需另外由印厂建立不透明白墨版；本文件中零 CMYK 的白色不代表已经具备白墨分色。亦可采用白纸印深底，让白色反白。
